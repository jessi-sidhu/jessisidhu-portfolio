AI agent that builds working circuits on a 3D breadboard through tool calls. A circuit simulator written from scratch (modified nodal analysis, the method SPICE uses) checks every build. Plume

code ↗

Query engine in Rust with no SQL: you build plans by chaining DataFrame methods. A fixed-point optimizer runs five rules, including predicate pushdown and column pruning, and Parquet row-group pruning skips 7 of 8 row groups on a selective filter. Every query is checked against DuckDB across 208 tests.
